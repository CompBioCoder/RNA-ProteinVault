# Dashboard Guide

返回 [[00_Home/RNA-Protein Research Hub|Research Hub]]。

- **Literature coverage**：Zotero 文献中带 PDF 与摘要的覆盖情况。
- **Vault health**：内部链接连通度与 Frontmatter 规范度。
- **Inbox**：`data/` 中等待处理的笔记。
- **Task flow**：全库 Markdown 复选框完成率。
- **Heatmap**：优先按 Zotero `dateAdded` 映射到 `created`。
- **Chapter actions**：扫描对应研究分类并把结果写入插件运行日志，不修改研究笔记。
