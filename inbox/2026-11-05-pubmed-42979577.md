PubMed · 2026-10-08 · Bioinform Adv · [原文](https://pubmed.ncbi.nlm.nih.gov/42979577/)

> [!abstract] Abstract
> In single-cell RNA sequencing data analysis, the same dataset can be examined from multiple complementary perspectives, each requiring different analytical strategies and potentially leading to distinct biological interpretations. Systematically exploring such diverse strategies in a reproducible and scalable manner remains challenging. We developed a framework combining large language model-based agents with workflow languages. Given an objective, the framework generates analytical strategies, converts each into a workflow plan, verifies that each plan reflects its intended strategy, executes accepted workflows in parallel, and integrates the outputs into a final report. Evaluation across three datasets and three large language models showed that plan validation improved the executable analysis intent fulfillment rate from 0.061 to 0.378. Diversity of analytical themes was established at as few as 10 generated strategies, while the number of distinct executable analysis paths grew continuously, reaching 59 unique paths at 100 generated strategies. Parallelization of both plan generation and workflow execution achieved up to a 29.9-fold speedup in workflow execution over sequential execution, with plan generation completing in near-constant time regardless of portfolio size. Source code is available at https://github.com/bioinfo-tsukuba/mpdas_paper under the MIT license.
